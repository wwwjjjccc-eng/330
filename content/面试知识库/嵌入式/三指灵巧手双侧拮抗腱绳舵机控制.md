# 三指灵巧手双侧拮抗腱绳舵机控制

> C99 控制模块：将 10 个关节的屈曲命令映射为 20 个 STS3215 位置目标，每个关节一对屈肌腱 / 伸肌腱舵机。

## 代码

- [C 接口头文件](https://github.com/wwwjjjccc-eng/330/blob/main/firmware/antagonistic_tendon/antagonistic_tendon.h)
- [C 实现](https://github.com/wwwjjjccc-eng/330/blob/main/firmware/antagonistic_tendon/antagonistic_tendon.c)
- [接线、标定与构建说明](https://github.com/wwwjjjccc-eng/330/blob/main/firmware/antagonistic_tendon/README.md)

当前 ORCA 三指配置按拇指 4 轴、食指 3 轴、中指 3 轴，共 10 个自由度组织。**双侧拮抗意味着每轴两台舵机，共 20 台**；这与现有“每自由度一台电机、单根腱牵引”的 10 电机方案不是同一套硬件，实施前需确认机械布置、供电和总线负载。

## 控制映射

每个关节输入归一化屈曲量 `q ∈ [0, 1]`：`q=0` 为张开，`q=1` 为闭合。屈肌和伸肌舵机分别使用各自标定的张开 / 闭合位置端点，控制器对两边都做插值，然后将 20 个目标通过同步写回调一次提交。每次更新的最大位置步长由 `max_step_per_update` 限制。

```c
/* 结构示意：位置必须来自实测，不能把示例值直接用于真机。 */
AT_Axis axes[AT_DOF_COUNT] = {0};
AT_Controller controller;

/* 对每个轴配置 flexor/extensor 的舵机 ID、两个标定端点，
 * 并先从舵机读回当前位置信息填入 current_position。 */
/* axes[i].flexor = ...; axes[i].extensor = ...; */

if (!at_init(&controller, axes, 8U)) {
    /* 配置非法：保持执行器未使能并上报错误 */
}

float flexion[AT_DOF_COUNT] = {0.0f};
/* 每个控制周期更新 flexion，再调用：
 * at_update(&controller, flexion, feetech_sync_write_positions, bus);
 */
```

## 移植边界和安全注意

- 代码只实现位置映射、命令范围检查和每周期步长限制；UART 半双工收发、协议帧、超时与错误恢复由 MCU 对应的 Feetech 总线驱动实现。硬件平台未指定，因此没有伪造某块开发板的寄存器或串口 API。
- 用同步写一次下发一对腱绳的目标，降低先动一边造成的瞬时松弛 / 过紧风险；控制循环仍需检查返回值，并实现通信 watchdog 与急停。
- **每个电机分别标定**方向和安全行程，低速、低负载逐对测试。端点应保持适度预紧，避免两侧同时松弛或互相过度拉紧。
- 这是位置控制示例，不具备腱张力 / 碰撞反馈，不能替代限流、负载监控、机械限位和断电急停。首次上电应架空手指、限制电流并随时断电。
